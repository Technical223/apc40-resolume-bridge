# Showcase media

Provided by the repository owner in `apc40-github-media.zip` for the project showcase. GIF and MP4 files preserve the supplied recordings; still images are resized JPEG copies of the supplied screenshots.

`12`–`15` are GIF excerpts from the owner's screen recording of the visualizer with live Arena content (cropped to the 3D view; 560 px, 10 fps). `10`–`11` are visualizer screenshots of the owner's private room (LED and projection space presets, v1.5.1) with generated red content; the model itself is not published.

These are example show recordings, not a promise that the pictured room, composition or physical fixture layout is included in the public installer. No Blender files, compositions, mappings or vendor installers are included here.
